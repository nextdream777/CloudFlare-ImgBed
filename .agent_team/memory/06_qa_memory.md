# 06_QA测试 长期提炼记忆库 (测试用例与漏测防护)

## 1. 自动化回归测试策略
* 核心测试框架: Mocha (`npm test`)。
* 集成端到端冒烟测试: `npm run ci-test` (通过 concurrently 拉起开发服务并用 wait-on 探测端口就绪后再执行测试)。

## 2. 重点防护区 (高危场景)
* **上传渠道容错**: 测试各渠道（Telegram, R2, S3）在网络超时或 Token 失效时的报错返回是否友好。
* **分片上传**: 测试网络意外中断后重传与边界分片拼接完整性。
* **鉴权拦截**: 确保 `/api/manage/*` 未授权请求 100% 返回 401，严禁越权漏洞。
