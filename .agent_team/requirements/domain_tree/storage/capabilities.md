# Storage 领域已生效业务能力清单 (Capabilities)

* [CAP-STORAGE-001] 支持多渠道文件上传（Telegram Bot, Discord Webhook, Cloudflare R2, S3-compatible, Hugging Face, WebDAV）。
* [CAP-STORAGE-002] 支持大文件分片上传 (Chunked Upload) 与合并。
* [CAP-STORAGE-003] 支持自定义上传目录与渠道动态指定。
* [CAP-STORAGE-004] 支持上传文件元数据自动解析（MIME类型、大小、MD5/SHA散列、上传IP与地理位置）。
* [CAP-STORAGE-005] 支持地理坐标（WGS-84）、地点名称与图文故事的物理列与 metadata JSON 双写持久化。
