# 历史版本归档：v2.9.x (Release Archive)

* **发布版本**: v2.9.0
* **基线时间**: 2026-09-21
* **关联需求工单**: `REQ-002` (原生 Vue 架构下的光影图志、多图志管理与全局标签治理闭环)
* **核心交付成果**:
  - **D1 增量数据模型与迁移**:
    - 新增数据表 `atlases`（图志元数据、封面与动态规则）与 `atlas_items`（手动策展收录映射表）；
    - 编写迁移脚本 `v2.9.0_add_atlas_and_settings.sql` 与 `d1Database.js` 扩展，增加级联删除清理防护。
  - **后端核心治理与空间 API**:
    - 图志 CRUD API (`/api/manage/atlas/[[path]].js`)：支持图志创建、编辑、列表、删除及封面自动回退自愈；
    - 全系统标签治理 API (`/api/manage/tags/governance.js`)：全量标签使用统计、跨标签重命名与合并、一键清理 0 引用死标签；
    - 系统设置扩展 (`/api/manage/sysConfig/page.js`)：动态配置高德 2.0 矢量底图参数（API Key、安全密钥、样式与 POI 标注开关）；
    - 足迹检索 API 升级 (`/api/manage/footprint.js`)：支持 `atlasId` 规则过滤，强制执行无坐标排除硬门禁。
  - **原生 Vue 3 SFC 迁移 (`PhotoAtlas.vue`)**:
    - 顶部悬浮控制岛：集成图志切换器、动态标签胶囊过滤、统计指标胶囊、打卡选点与图志管理快捷入口；
    - 双底图自适应引擎：系统配置高德 Key 时自动启用高德 2.0 WebGL 矢量底图（强制剔除商业 POI），未配置时无缝平滑降级至 Leaflet 浅色栅格底图；
    - 故事手记抽屉与微型选点打卡弹窗：支持图文故事展示、坐标转换（WGS-84 <-> GCJ-02）与双向更新。
  - **上传端空间交互闭环 (`UploadHome.vue` / `UploadForm.vue` / `UploadFileItem.vue`)**:
    - 引入纯前端轻量 EXIF 读取器 (`exifReader.js`)，文件选择时自动嗅探 GPS，并在卡片上点亮定位状态徽标；
    - 上传时将经纬度自动带入入库请求；
    - 上传完成面板对无坐标照片提供「一键批量标定」交互，统一赋予地点坐标。
  - **独立双页签管理页面 (`AtlasManage.vue`)**:
    - Tab 1 (图志编排)：16:9 卡片网格呈现，系统主图志置顶锁定，自定义图志支持规则编辑、图卷跳转与删除确认；
    - Tab 2 (标签治理)：直观表格展示关联照片数与带坐标比例，支持重命名合并与清理死标签。
  - **工程直连构建与词汇规范**:
    - `Sanyue-ImgHub/vue.config.js` 输出直连 `CloudFlare-ImgBed/frontend-dist`，`npm run build` 成功通过（退出码 0）；
    - 全项目 100% 彻底消除「大盘」二字，全域统一采用「光影图志」，大图视图统一采用「图卷」。
