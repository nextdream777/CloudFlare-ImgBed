# REQ-001 界面交互规格与行为法典 (UI & Interaction Spec)

## 1. 动效与微交互标准 (Motion Standards)
- **通用微交互**：`150ms ~ 200ms ease-out`（按钮 Hover 变深、标签点击切换、输入框 Focus 发光）。
- **容器与弹层动效**：`300ms cubic-bezier(0.16, 1, 0.3, 1)`（右侧抽屉从视口外平滑滑入、选点弹窗轻微缩放淡入）。严禁使用超过 400ms 的拖沓动画。
- **地图移动平滑度**：缩放与平移使用 Leaflet 原生惯性插值，点聚合展开（Spiderfy）持续时间 `200ms`。

## 2. 交互行为与时序矩阵 (Interaction Matrix)

| 触发控件 (Trigger) | 用户动作 (Event) | 中间过渡态 (In-Flight) | 终态反馈与结果 (Feedback & Result) | 交互容器类型 |
| :--- | :--- | :--- | :--- | :--- |
| **顶部目录下拉框** | 选择新目录（如 `/travel/`） | 下拉收起，地图标记渐变淡出 (150ms) | 地图视野自动平移缩放至该目录下所有点位的包围盒 (Bounding Box)，更新足迹计数 | 悬浮导航栏 (Floating Bar) |
| **标签药丸 (Tag Pill)** | 点击单项标签（如 `Landscape`） | 胶囊背景色瞬时切换高亮态 | 地图标记点毫秒级过滤显示/隐藏，右侧若有打开的抽屉同步刷新 | 悬浮导航栏 |
| **地图聚合点 (Cluster)** | 点击聚合球 (如 `[48]`) | 缩放级别 +2，地图平滑平移居中 | 聚合球散开为次级聚合球或单点相机图钉 | 地图画布 |
| **地图单点图钉 (Pin)** | 点击单张照片图钉 | 图钉微弹跳放大 (Scale 1.15) | 右侧抽屉平滑滑出 (300ms)，居中呈现地点标题、日期、照片网格与故事长文 | 右侧抽屉 (Drawer, 420px) |
| **抽屉关闭按钮 / 遮罩** | 点击 `✕` 或点击地图空白区 | 抽屉向右平滑滑出视口 (250ms) | 抽屉隐藏，地图图钉恢复常态尺寸 | 右侧抽屉 |
| **图片详情「打卡/编辑」** | 点击管理列表的编辑图标 | 背景微模糊，弹窗淡入居中 | 呈现分屏/分块选点面板，微观测绘地图自动定位至已有坐标（若有） | 模态弹窗 (Modal, 720px) |
| **选点地图画布** | 点击地图任意有效位置 | 点击处出现微扩散水波纹 (Wave Pulse) | 图钉吸附落于该点，经纬度字段实时更新，启动前端辅助逆地理编码请求 | 选点拾取器 (Point Picker) |
| **逆地理编码请求** | 图钉落下后异步触发 | 「地点名称」输入框显示淡灰色“正在获取地名...” | 自动填入推荐地名（如“浙江省·杭州市·西湖区”），光标自动聚焦方便修改 | 输入框辅助 |
| **打卡保存按钮** | 点击「保存」 | 按钮呈现 Spinner 旋转 + `disabled` 防重 | 接口保存成功：关闭弹窗 + 顶部绿色 Toast“已成功更新地点与故事” + 列表静默刷新 | Toast 反馈 |

## 3. 防呆与防御性交互准则 (Defensive UX)

1. **防重复提交 (Debounce & Disable)**：点击保存后立即禁用提交按钮，直到后端响应，严禁连击产生脏数据。
2. **清除定位保护**：点击「清除定位」按钮时，弹出气泡微确认：“确定清除该照片的 GPS 坐标吗？清除后将不再出现在地图大盘中。”
3. **坐标合法性防御**：纬度限定在 `[-90, 90]`，经度限定在 `[-180, 180]`，超出范围标红阻断，严禁非法浮点数提交。
4. **长文本折叠与自适应**：游记故事若超过 200 字，在抽屉列表中默认展开前 4 行，底部提供「展开全文」文字按钮，点击平滑展开。

## 4. 四象限状态机定义 (State Machine)

| 状态类型 | 表现特征与交互规范 |
| :--- | :--- |
| **加载状态 (Loading)** | - **大盘初次进入**：全屏底图渐变淡入，顶部控制岛显示骨架微光 (Shimmer)，数据拉取中不阻塞地图拖拽。<br>- **抽屉拉取详情**：照片网格展示 4 块灰色圆角骨架占位块，加载完成后无缝淡入。 |
| **空数据状态 (Empty)** | - **无任何足迹照片**：地图居中显示世界视图，右侧或顶部浮窗温和提示：“暂无包含地理标记的照片，上传带有 GPS 的照片或在管理后台手动打卡即可点亮足迹。”附带「去上传」快捷按钮。<br>- **筛选后无结果**：提示“当前筛选条件下未找到足迹点”，提供「重置筛选」按钮。 |
| **异常状态 (Error)** | - **地图瓦片加载失败/离线**：底图显示优雅降级淡灰底色与网格，界面顶部浮出微提示：“地图瓦片连接不稳定，照片数据正常保留中”。<br>- **逆地理反查超时**：输入框保持为空并提示“未能自动获取地名，可手动输入”，绝不阻断用户保存经纬度。 |
| **成功正常状态 (Success)** | - 正常渲染高对比度柔和地图、聚合球与图钉；抽屉内容完整，图片带预加载渐入。 |

## 5. 响应式布局断点 (Responsive Breakpoints)

- **桌面端 (`>= 1024px`)**：
  - 顶部悬浮控制岛居中（Max-width 900px）；
  - 右侧抽屉固定宽度 420px，与地图平级浮动；
  - 选点弹窗宽度 720px，地图选点与表单并排或上下双层舒适布局。
- **移动端/窄屏 (`< 768px`)**：
  - 顶部控制岛全宽自适应，内嵌水平横向滑动的标签栏；
  - 右侧抽屉自动切换为**底部滑出抽屉 (Bottom Sheet · 占用屏幕高度 65%)**，支持手势下滑关闭；
  - 选点弹窗全屏覆盖，地图在上方占 45%，下方为滚动表单。
